## 🌊 About

*Hacker House Goa 2026* is an interactive web experience designed around the Hacker House Goa event.

The website combines an event-focused visual experience with a personalized *Builder Pass / ID Card Generator*.

Visitors can:

- 🌴 Explore the Hacker House Goa experience
- 🪪 Create a personalized Builder Pass
- 📸 Upload and crop their profile photo
- 🔍 Adjust photo positioning and zoom
- 🧑‍💻 Add their name and role
- 🎨 Generate a customized ID card directly in the browser
- 💾 Download the generated Builder Pass
- 𝕏 Share their Builder Pass through X
- ⚡ Experience animated and interactive UI elements

The project is designed to work as a *static client-side application*, making it simple and fast to deploy on Vercel.
