## Important

Do not redesign the homepage into a generic SaaS landing page.

Do not use:

- generic gradients
- glassmorphism
- generic cards
- generic AI landing-page layouts
- excessive rounded cards
- stock photography
- generic illustrations

The reference image should guide the composition, visual hierarchy, typography, color palette and overall atmosphere.

The implementation should be original code and should not blindly trace or copy another website.

## Responsive Direction

Desktop should preserve the editorial composition.

Tablet and mobile should intentionally rearrange the composition rather than simply scaling the desktop layout down.
